# Дефектная ведомость

Бесплатные приборы, которые считают целиком в браузере. Ни файл, ни введённые цифры
никуда не отправляются — сервер не видит ничего. Форм заявки на страницах нет намеренно.

- **[Что на самом деле лежит в вашей выгрузке товаров](https://felxmodaso-collab.github.io/vedomost/katalog/)** —
  сколько позиций живых, сколько описано на бумаге и сколько на самом деле, есть ли цены
  и фотографии, какие поля завели и не ведут, сколько внутри мусора. Читает `xlsx`, `csv`
  и тот `.xls`, внутри которого на самом деле веб-страница.
- **[Сколько стоит рутина, которую делают руками](https://felxmodaso-collab.github.io/vedomost/ruchnaya-rabota/)** —
  часы в год, деньги в год с учётом взносов и рабочего места, какая доля работы реально
  снимается программой и за сколько окупится. Если не окупится — так и скажет.
